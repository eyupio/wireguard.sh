Run one of the following commands to automatically install WireGuard.

Supported on Ubuntu, Debian, CentOS & Fedora.

bash <(wget -q -O - https://wireguard.sh/wireguard.sh)

or

bash <(curl -s https://wireguard.sh/wireguard.sh)

wireguard.sh:~$ Ready for your next command.

What the script does

  • Installs WireGuard and writes /etc/wireguard/wg0.conf.
  • Enables IP forwarding and configures firewall/NAT for the VPN subnet.
  • Creates your first client config and prints a QR code.
  • Re-run the same command any time to add or remove clients, or uninstall WireGuard.

Before you run it

  • Use a fresh server you control; the script needs root.
  • Ubuntu 18.04+, Debian 10+, CentOS 7+ or Fedora 31+.
  • Opens one UDP port, 51820 by default.
  • Read the installer before piping it to bash.

After the server is up

Install the WireGuard client on your phone or laptop, then import the generated config or scan the QR code.
