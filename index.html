Run one of the following commands to start the guided installer.

The TUI opens on your server. Nothing changes until you confirm.

bash <(wget -q -O - https://wireguard.sh/wireguard.sh)

or

bash <(curl -s https://wireguard.sh/wireguard.sh)

wireguard.sh:~$

What the TUI does

  • Detects your OS, IPv4 and IPv6 addresses, then explains what it found.
  • Asks for the port, first client name and DNS resolver with sensible defaults.
  • Shows a review screen before installing anything.
  • Installs WireGuard, writes /etc/wireguard/wg0.conf, and configures forwarding, firewall and NAT.
  • Reports each install step and keeps the full log at /var/log/wireguardSH.log.

Before you run it

  • Use a fresh server you control; the installer needs root.
  • Ubuntu 18.04+, Debian 10+, CentOS 7+ or Fedora 31+.
  • Opens one UDP port, 51820 by default.
  • Read the installer before piping it to bash.

After the server is up

Install the WireGuard client on your phone or laptop, then import the generated config or scan the QR code.
